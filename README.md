# RO — منصة الجرد

واجهة عربية متجاوبة لإدارة عمليات الجرد المفتوح والجرد بمرجع، مع واجهات الشركة والمسؤول والموظف وإدارة المنصة.

نسخة تجريبية: البيانات والحسابات والطلبات محفوظة محليًا في المتصفح. ربط Google Sheets وApps Script والمزامنة وعزل الشركات وتقييد الأجهزة فعليًا لم تُفعّل بعد.

## التشغيل
اخدم مجلد dist بأي خادم ملفات ثابتة، وافتح index.html.

## الاختبارات
```sh
node tests/core.cjs
node tests/workflows.cjs
node tests/platform.cjs
```

backend/Schema.gs أساس مخطط Google Sheets فقط، ولا يقدم API أو تسجيل دخول فعليًا.

مصدر الموقع المستضاف يُدار منفصلًا؛ رفع الكود هنا لا يفعّل الاستضافة أو قاعدة البيانات تلقائيًا.
